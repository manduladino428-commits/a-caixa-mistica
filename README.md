# A Caixa Mística — AI stone readings, paid on-chain

**Live:** https://acaixamistica.com · **Hackathon:** Colosseum Crypto World's Fair 2026 · **Team:** Marcelo Freitas (solo founder, Teresina, Brazil)

A Caixa Mística pairs a handcrafted wooden box of crystals with an AI app. A user photographs a stone; the AI identifies it and writes a personal reading (Past, Present, Daily Reflection, Number and Color of the Day) in English or Portuguese. A free preview shows the Past. The full reading is unlocked with a **USDC micro-payment on Solana** via **Solana Pay**.

## Why Solana
Card and cross-border rails make a $0.10 global purchase impossible. Solana Pay + USDC gives sub-cent fees, ~1s finality and a stable price, so anyone on Earth can pay with a wallet like Phantom — no card, no bank.

## How the payment works
1. User clicks **Unlock with USDC (Solana)**. The app creates a `SolanaPayment` record with a random `reference` key and a **unique amount** (e.g. `0.100437` USDC).
2. It renders a Solana Pay transfer request as a QR code:
   `solana:<recipient>?amount=<amount>&spl-token=<USDC mint>&reference=<reference>&label=A%20Caixa%20Mistica`
3. The user scans with Phantom (or any Solana wallet) and approves.
4. The app polls Solana JSON-RPC every 3s:
   - **Path A:** `getSignaturesForAddress(reference)` → `getTransaction` and validate.
   - **Path B (fallback):** some wallets drop the reference key, so the app also scans recent signatures of the recipient's USDC token account and matches the **exact unique amount**, from `meta.preTokenBalances` / `meta.postTokenBalances`, treating a missing pre-balance as 0.
5. On a valid match it stores the signature, marks the payment `confirmed`, unlocks the reading and shows a Solscan link. Each signature can unlock only one payment.

## Stack
- **Base44**: React web app, hosting, database, auth, built-in LLM for stone vision and readings
- **Solana Pay** URL spec, **USDC (SPL)** on Solana mainnet, Solana JSON-RPC with public RPC failover
- **Phantom** wallet, **Solscan**
- EN/PT internationalization
- Built by a solo founder using AI tools (Base44 AI builder and Claude by Anthropic)

## About this repository
The full app runs on Base44, a hosted app builder. This repository contains the source files written during the hackathon for the Solana Pay integration: payment creation, QR modal, on-chain verification, premium unlock screen and admin payments page. Platform scaffolding generated by Base44 is not included.

## Admin
An admin page lists all payments (date, user, unique amount, reference, status, Solscan link) with a re-verify action. A paywall on/off toggle and the USDC price are editable without code.
